# Bearbiz

Bearbiz is a custom BI platform for weekly report uploads, PDF extraction, dashboarding, and printable/exportable sales reporting.

## Current version

`0.0.1`

## Initial goals

- Upload one report at a time
- Extract stable weekly PDF report data into structured storage
- Show per-report dashboards and one overall dashboard
- Export customizable PDF reports
- Keep the Docker setup minimal
- Add report types later without rewriting the app

## Working rules

- Semantic versioning from the start
- One report at a time
- Shared core + per-report modules
- Kanban-driven tasking
